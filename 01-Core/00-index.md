# 01 Core — inventory

Scope: Core owns the self-contained foundation types for GNU C++20 contest code: template and debug, machine-word reduction, modular integers, arbitrary-precision and fixed-width integers, rationals, dense/GF(2)/sparse matrices, the accelerated polynomial/FPS engine and the dynamic bitset. Mathematics owns ordinary scalar number theory, integer roots, combinatorics, scalar transforms/FPS/linear-algebra duplicates and probability/Markov models; Data Structures owns succinct and dynamic rank/select bit vectors. Full types are extreme-optimization targets, so their Operations cells also name the required backend variants; minis are independently copyable reductions with identical results on the shared domain. Contracts live in [00-notes.md](Docs/00-notes.md) and the source ledger in [00-sources.md](Docs/00-sources.md).

## Notes

- Integer roots (isqrt/icbrt/kth root with remainder, perfect-power tests) on native words are Mathematics `21-integer_roots.hpp`; overflow-checked powers are Mathematics `01-mod_arithmetic.hpp`; InfInt keeps its own big-integer roots.
- Primitive roots, discrete logarithms, composite-modulus roots, CRT and finite-field extensions are Mathematics families; a residue type does not claim them.
- Markov-chain models and stationary-distribution theory are Mathematics `26-probability.hpp`; SparseMatrix only provides the iteration primitives named above.
- Scalar convolution/FPS/linear-algebra/linear-recurrence headers in Mathematics intentionally duplicate Core Poly/Matrix functionality without ISA kernels.
- Succinct and dynamic rank/select bit vectors are Data Structures `40`/`49`; `std::bitset` stays the compact fixed-size alternative.
- The incremental XOR linear basis and its prefix/range variants are Data Structures `62-xorbasis.hpp`; BitMatrix owns packed GF(2) matrices, elimination and subspace operations.
