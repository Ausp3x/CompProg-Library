# 01 Core — inventory

Scope: Core owns the self-contained foundation types for GNU C++20 contest code: template and debug, machine-word reduction, modular integers, arbitrary-precision and fixed-width integers, rationals, dense/GF(2)/sparse matrices, the accelerated polynomial/FPS engine and the dynamic bitset. Mathematics owns ordinary scalar number theory, integer roots, combinatorics, scalar transforms/FPS/linear-algebra duplicates and probability/Markov models; Data Structures owns succinct and dynamic rank/select bit vectors. Operations cells of full types also name their backend variants (profiles in `01-principles.md`). Folder-wide contracts live in [00-notes.md](Docs/00-notes.md) and the source ledger in [00-sources.md](Docs/00-sources.md).
