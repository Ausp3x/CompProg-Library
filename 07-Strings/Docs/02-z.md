# 02-z.hpp — evidence

`02-z.hpp` (batch ST01, package P016) provides the Z function, sentinel-free extended Z (pattern against text), Z-based occurrences, borders and periods, and exact prefix/Z validation and conversion. Contest profile, GNU C++20, no ISA code. It includes `01-prefixfunction.hpp` for the witness and the symbol comparison.

## Contracts

Common domain as in [01-prefixfunction.md](01-prefixfunction.md): random access and equality, length below `INT_MAX`, every byte and the full integer range valid, no sentinel. Pattern and text are accessed by index only.

### zFunction

`z[i] = LCP(s, s[i, n))` with `z[0] = n`; empty input returns `[]`. O(n) time and returned storage. Correctness: the rightmost prefix-matching box `[l, r)` gives `z[i] >= min(z[i-l], r-i)` inside it; further comparisons push `r` right, at most n times.

### extendedZ, zOccurrences

`extendedZ(pattern, text)` returns n entries, `res[i] = LCP(pattern, text[i, n))`; an empty pattern gives n zeros and no synthetic end position. Pattern and text symbols are compared with `KmpMatcher<>::same`, so differing integral types compare by exact value (an unsigned `UINT_MAX` never equals a signed `-1`). `zOccurrences` lists every overlapping start ascending; an empty pattern gives `0..n`. O(n + m) time; O(n + m) and O(n + m + out) space. Correctness: pattern Z values inside a text match box and the same right-boundary argument; keeping the sequences separate avoids any sentinel or alphabet restriction.

### zBorders, zPeriods, zPeriod

Valid `z` required (not rechecked). `zBorders(z, include_full = false)` lists positive borders ascending (`k` is a border iff `z[n-k] = k`), with n only if `include_full`; `zPeriods(z)` lists every positive period ascending including n (`p` is a period iff `z[p] = n - p`); `zPeriod(z, whole = false)` is the smallest period, or with `whole = true` the smallest period dividing n; empty gives 0. O(n) time; lists cost O(out).

### prefixToZ, zToPrefix, validZFunction

Exact checked conversions in O(n) time and space; the bool distinguishes a valid empty input from failure. On failure the output is cleared. The output may alias the input (temporaries hold every read). `z[0] = n` is enforced strictly; `validZFunction` imposes no fixed alphabet size.

Correctness: `prefixToZ` builds the witness of `validPrefixFunction(pi, s)` and returns `zFunction(s)`. `zToPrefix` fills, for every start `i` and backwards from `i + z[i] - 1`, the unset endpoints with prefix lengths; an endpoint already set was covered by an earlier and therefore longer start, so each entry is written once and the work is linear. The resulting candidate is validated through the witness, and the witness's Z array is recomputed and compared, which rejects locally bounded but globally inconsistent inputs.

## Feature-to-test map

Runner: [`02-z_tester.py`](<../../96-Local Testing/07-Strings/02-z_tester.py>). Oracles: direct LCP scans and restricted-growth alphabet partitions; all checks survive `-DNDEBUG`.

| Operation | Coverage |
|---|---|
| zFunction | Exhaustive binary strings, random signed symbols, all 256 bytes, signed 64-bit extremes, index-only sequences, million-symbol unary and near-unary. |
| extendedZ, zOccurrences | All bounded pattern/text pairs and random pairs against naive LCP/matches; embedded NUL matching; mixed-signedness differential (ulng pattern against lng text) through an exact-value id oracle and the `uint`/`ulng`/`ulll` versus `int -1` regressions; index-only pattern and text; 1000-symbol pattern against the large unary text. |
| zBorders, zPeriods, zPeriod | Direct border/period definitions on every tested string, proper and full borders, divisor-restricted roots. |
| prefixToZ, zToPrefix, validZFunction | Every range-valid Z array through length 5/8/9 against the partition-derived feasible map (status and converted array); valid conversions both ways with and without aliasing; invalid extremes (`-1`, `INT_MAX`, `INT_MIN`, wrong `z[0]`) clear aliased and separate outputs; million-entry conversion. |

Checked builds run three assertion probes (oversized sequence, oversized pattern, oversized text).

## Sources

Code is independently implemented from the algorithmic invariants.

- [cp-algorithms, Z-function and its calculation](https://cp-algorithms.com/string/z-function.html): rightmost box, linear proof, matching and period applications (its `z[0] = 0` convention is deliberately replaced by `z[0] = n`).
- [OI Wiki, Z 函数（扩展 KMP）](https://oi-wiki.org/string/z-func/): independent presentation of box reuse.
- [Nyaan `string/z-algorithm.hpp`](https://github.com/NyaanNyaan/library/blob/master/string/z-algorithm.hpp) and [ACL `z_algorithm`](https://github.com/atcoder/ac-library/blob/master/atcoder/string.hpp): behavior comparison for empty input and `z[0] = n`.
- Catalog sweep 2026-10-08 (cp-algorithms, KACTL, ACL, maspypy, Nyaan, ei1333, hitonanode, OI Wiki, Library Checker `zalgorithm`) in [00-sources.md](00-sources.md): nothing missing; incremental Z belongs to row `30`, `is_substring` to `16`, inverse Z to `31`.
- Preserved `OLD/Team Notebook/src/misc/old_zalgo.cpp` (static Z, `z[0] = n`, global storage) is accounted for here; original bytes unchanged.

## Limits and handoffs

- Validity of `z` for the border and period helpers is a caller precondition.
- Online Z, minimum-alphabet reconstruction and advanced periodicity remain with rows `30`, `31`, `26`/`27`.
- Exact GCC 14.2 and the Windows build were not run.
