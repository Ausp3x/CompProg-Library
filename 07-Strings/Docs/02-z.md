# 02-z.hpp — Evidence

`02-z.hpp` (batch ST01, package P016) provides the Z function, sentinel-free extended Z (pattern against text), Z-based occurrences, borders and periods, exact prefix/Z validation and conversion, and a double-ended distinct-substring counter. Contest profile, GNU C++20, no ISA code. It includes `01-prefixfunction.hpp` for the witness and the symbol comparison.

## Contracts

The common domain is that of [01-prefixfunction.md](01-prefixfunction.md): random access and equality, length below `INT_MAX`, every byte and the full integer range valid, no sentinel. Pattern and text are accessed by index only.

### zFunction

`z[i] = LCP(s, s[i, n))` with `z[0] = n`; empty input returns `[]`. O(n) time and returned storage. Correctness: the rightmost prefix-matching box `[l, r)` gives `z[i] >= min(z[i-l], r-i)` inside it; further comparisons push `r` right, at most n times.

### extendedZ, zOccurrences

`extendedZ(pattern, text)` returns n entries, `res[i] = LCP(pattern, text[i, n))`; an empty pattern gives n zeros and no synthetic end position. Pattern and text symbols are compared with `KmpMatcher<>::same`, so differing integral types compare by exact value (an unsigned `UINT_MAX` never equals a signed `-1`). `zOccurrences` lists every overlapping start ascending; an empty pattern gives `0..n`. O(n + m) time; O(n + m) and O(n + m + out) space. Correctness: pattern Z values inside a text match box and the same right-boundary argument; keeping the sequences separate avoids any sentinel or alphabet restriction.

### zBorders, zPeriods, zPeriod

These require a valid `z`, which is not rechecked. `zBorders(z, include_full = false)` lists the positive borders ascending (`k` is a border iff `z[n-k] = k`), with n only if `include_full`. `zPeriods(z)` lists every positive period ascending, n included (`p` is a period iff `z[p] = n - p`). `zPeriod(z, whole = false)` is the smallest period, or with `whole = true` the smallest period dividing n; empty gives 0. O(n) time; lists cost O(out).

### prefixToZ, zToPrefix

Exact checked conversions in O(n) time and space. The bool distinguishes a valid empty input from failure, so `zToPrefix` is also the Z-array validator. On failure the output is cleared. The output may alias the input, since temporaries hold every read. `z[0] = n` is enforced strictly; validity imposes no fixed alphabet size.

Correctness: `prefixToZ` builds the witness of `validPrefixFunction(pi, s)` and returns `zFunction(s)`. `zToPrefix` fills, for every start `i` and backwards from `i + z[i] - 1`, the unset endpoints with prefix lengths; an endpoint already set was covered by an earlier and therefore longer start, so each entry is written once and the work is linear. The candidate is then validated through the witness, and the witness's Z array is recomputed and compared, which rejects locally bounded but globally inconsistent inputs.

### DistinctSubstringsDeque

`DistinctSubstringsDeque<T = char>` keeps a deque `s` of symbols and `total`, the exact number of distinct non-empty substrings of `s` (empty gives 0); `distinctSubstrings()` returns it in O(1). `pushBack(c)`, `pushFront(c)`, `popBack()` and `popFront()` each run one `zFunction` over `s` or its reversal, so an update costs O(n) time and O(n) workspace for the current length n. The reversal is the index-only `Reversed` view, with no copy; `std::views::reverse` gives the same values but builds a debug iterator on every access, which made the checked build markedly slower.

Symbols are compared with `T`'s `==`; any equality type works, every byte and the full integer range included. The length stays below `INT_MAX` (asserted by the push's `zFunction`), and `total <= n(n+1)/2` fits `lng`. A pop asserts a non-empty deque and is a no-op on an empty one under `NDEBUG`. Copies are independent; reassign a moved-from deque before use (its `total` keeps the old count). `s` and `total` are public only because the library has no `private`, and must not be edited apart.

Correctness: a substring that occurs in `v` but not in `v` minus its first symbol is a prefix of `v` that occurs nowhere else. Prefixes recurring elsewhere are closed downward, and the longest has length `max(z[i], i >= 1)`. So `fresh(v) = |v| - max z` counts the substrings that `pushFront` adds (applied to the new `s`) and `popFront` removes (applied before removal). The back operations apply the same count to the reversed view, which turns suffixes into prefixes. No index in the folder supports edits and pops at both ends together; the append-only case (`distinctSubstringsOnline`, row `10`) and the queue case (`SlidingWindowSuffixAutomaton`, row `44`) are faster ([00-notes.md](00-notes.md), Ownership inside the folder).

## Limits and Handoffs

- Validity of `z` for the border and period helpers is a caller precondition.
- `DistinctSubstringsDeque`: a `total` above `INT_MAX` is argued (`n(n+1)/2 < 2^63` for `n < INT_MAX`), not reached by a test; the largest tested total is 90,002 in stress and 30,002 in full. Random sequences stop at 150 symbols over at most 4 symbols; the large cases are unary, near-unary and alternating. The length precondition (a push at `INT_MAX - 1` symbols) and the `NDEBUG` no-op pop are untestable (Mutation Testing).
- Online Z, minimum-alphabet reconstruction and advanced periodicity stay with rows `30`, `31` and `26`/`27`.
