# 07 Strings — feature inventory

All nine Basic headers are **verified** by [P016 evidence](94-p016.md) and [P017 evidence](89-p017.md); the remaining 40 headers are **planned**. Existing notebook/monolith excerpts remain preserved **legacy references**. Basic/Advanced/Esoteric are inventory tiers, not directories; unselected rows remain separate future work.

The feature contracts include named research variants. Sources are starting points with the precise read scope below, not proof that every variant is implemented or every cited paper has been read. For a selected row, settle algorithm/domain/precondition details and verification before marking it complete.

## Representation, ownership and validation contracts

- Bytes are the default. State byte/code-point/integer-alphabet indexing, alphabet compression and sentinel conventions; support empty inputs, embedded NUL and the full byte alphabet within the declared domain.
- Distinguish substring, subsequence, edit-distance and Hamming-distance problems. Counts state exact/modular/saturated arithmetic, and witnesses/ties use a documented convention. Transition storage and alphabet size appear in time/memory bounds.
- Hashes are probabilistic fingerprints. A Monte Carlo API must say so; exact equality/LCE uses deterministic verification or an exact data structure. Do not silently report fingerprints as proof. Randomized runtime and randomized correctness are separate classifications.
- Offline suffix-tree topology lives in suffixtree; append-only Ukkonen in onlinesuffixtree. LZ parsing lives in zivlempel; grammar/SLP in grammar_compression. Two-way matching lives in string_matching, with proofs/rare alternatives in linear_string_algorithms. Each callable implementation has one owner; adapters may reuse it.
- Strings owns prefix/radix dictionaries; Data Structures owns binary integer/XOR tries and succinct rank/select engines. Miscellaneous owns generic optimal prefix coding; Mathematics owns convolution and combinatorial sequence counting.
- Differentially test matching with naive scans, suffix order with sorted suffixes, LCP with direct scans, substring/palindrome counts with sets, reconstruction by recomputing its input arrays and compression by decode/roundtrip. Include all-equal/periodic/adversarial alphabets, repeated patterns, empty patterns and edits that invalidate old states.
