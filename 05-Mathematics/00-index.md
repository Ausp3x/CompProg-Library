# 05 Mathematics — Inventory

Scope: ordinary scalar number theory, combinatorics, polynomial and linear-algebra algorithms, numerical methods, games, probability and DP optimization, as contest implementations. Core owns the accelerated reduction, modint, big-integer, rational, matrix, bitset and polynomial/FPS types; rows that intentionally duplicate scalar Core Poly or Matrix functionality still list every operation. Graphs owns graph-facing counting, Geometry lattice counts in polygons, Data Structures the convex-hull-trick and Li Chao engines, and Miscellaneous slope trick, bit tricks, enumeration and digit DP. Contracts, ownership boundaries and row notes live in [00-notes.md](Docs/00-notes.md), sources and source keys in [00-sources.md](Docs/00-sources.md).
