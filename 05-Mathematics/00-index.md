# 05 Mathematics — inventory

Scope: ordinary scalar number theory, combinatorics, polynomial and linear-algebra algorithms, numerical methods, games, probability and DP optimization written as contest implementations. Core owns the accelerated reduction, modint, big-integer, rational, matrix, bitset and polynomial/FPS types; rows `12`, `13`, `14`, `15`, `16` and `22` intentionally duplicate scalar combinatorial-series, transform, FPS, recurrence, matrix and interpolation versions and list every operation anyway. Graphs owns graph-facing counting, Geometry owns lattice counts in polygons, Data Structures owns the convex-hull-trick/Li Chao engines and Miscellaneous owns slope trick, bit tricks, enumeration and digit DP. Contracts and row notes live in [00-notes.md](Docs/00-notes.md), the source ledger in [00-sources.md](Docs/00-sources.md).

## Notes

- Core `16-poly.hpp` owns full composition and compositional inverse (`14` keeps scalar duplicates, `40` Lagrange inversion as coefficient extraction); Core `10-matrix.hpp` owns characteristic/minimal polynomial and Frobenius/Jordan forms (`44` keeps the scalar Hessenberg/Berkowitz/black-box algorithms); Core `14-sparsematrix.hpp` keeps its fixed-iteration `steadyState`, `26` the stationary distributions that test irreducibility.

- `27` owns Monge/Knuth/Aliens DP optimizations; Miscellaneous `34-slope_trick.hpp` owns slope trick and Data Structures `22-convexhulltrick.hpp` owns the line containers it bridges to.
