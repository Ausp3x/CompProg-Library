# 05 Mathematics — inventory

Scope: ordinary scalar number theory, combinatorics, polynomial and linear-algebra algorithms, numerical methods, games, probability and DP optimization written as contest implementations. Core owns the accelerated reduction, modint, big-integer, rational, matrix, bitset and polynomial/FPS types; rows `13`, `14`, `15` and `22` intentionally duplicate scalar transform/FPS/interpolation versions and list every operation anyway. Graphs owns graph-facing counting, Geometry owns lattice counts in polygons, Data Structures owns the convex-hull-trick/Li Chao engines and Miscellaneous owns slope trick, bit tricks, enumeration and digit DP. Contracts, ownership rules and the source ledger live in [80-notes.md](80-notes.md) and [81-sources.md](81-sources.md).

## Notes

- Core `16-poly.hpp` owns the accelerated FPS engine and `10-matrix.hpp` the full matrix type; rows `13`, `14`, `15`, `16`, `22` are scalar contest duplicates and never include an aggregate.
- XOR linear basis is not owned here: Core `12-bitmatrix.hpp` owns packed GF(2) subspaces, Python `_22_bitset.py` has it, and the incremental contest basis is recommended for Data Structures.
- Lattice counts inside polygons belong to Geometry `19-lattice_geometry.hpp`; `34` and `55` own only the arithmetic circle and curve counts.
- `27` owns Monge/Knuth/Aliens DP optimizations; Miscellaneous `34-slope_trick.hpp` owns slope trick and Data Structures `22-convexhulltrick.hpp` owns the line containers it bridges to.
- Graph-facing counting (LGV, BEST, Tutte) is Graphs `53-graph_counting.hpp`; kernels stay in `23`, `48` and `67`.
- Integer roots are canonical in `21`; `17` and `55` call them. Inverse tables live in `09`, divisor and multiple zeta/Möbius transforms in `24`.
- Carmichael lambda in `08` composes by lcm over prime powers; it is not multiplicative in the ordinary product sense.
- Distinct-subsequence counting, digit sums, Gray codes, base conversion and random sampling are Strings/Miscellaneous families and are listed in [81-sources.md](81-sources.md) as not adopted.
