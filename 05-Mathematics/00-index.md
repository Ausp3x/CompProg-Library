# 05 Mathematics — inventory

Scope: ordinary scalar number theory, combinatorics, polynomial and linear-algebra algorithms, numerical methods, games, probability and DP optimization written as contest implementations. Core owns the accelerated reduction, modint, big-integer, rational, matrix, bitset and polynomial/FPS types; rows that intentionally duplicate scalar Core Poly/Matrix functionality list every operation anyway. Graphs owns graph-facing counting, Geometry owns lattice counts in polygons, Data Structures owns the convex-hull-trick/Li Chao engines and Miscellaneous owns slope trick, bit tricks, enumeration and digit DP. Contracts, ownership boundaries and row notes live in [00-notes.md](Docs/00-notes.md), the source ledger and source keys in [00-sources.md](Docs/00-sources.md).
