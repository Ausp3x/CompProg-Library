# 06 Miscellaneous — inventory

Scope: reusable contest algorithms and utilities whose primary API is not owned by another topic: randomness, hashing, I/O, compression, bit and permutation tools, sequence/interval/offline patterns, enumeration, knapsack and the generic DP, search and heuristic engines. Mathematics owns the canonical search facade target, algebraic transforms, DP optimizations (Monge/Knuth/SMAWK/alien) and combinatorial counts; Graphs owns explicit-graph shortest paths, tree DP engines and Hamiltonian/TSP APIs; Data Structures owns range-query engines, Mo, heaps and rollback/persistent containers; Strings owns text indexes and LCS. Contracts and ownership rules are in [00-notes.md](Docs/00-notes.md); the source ledger is in [00-sources.md](Docs/00-sources.md).

## Notes

- `05-binarysearch.hpp` defines nothing: it includes Mathematics `02-search_algorithms.hpp`, the canonical owner of integer/real binary, ternary and golden-section search. Mathematics `27-optimization.hpp` owns Monge/Knuth/SMAWK/alien adapters; `52` and `34` call them, never re-implement them.
- Boolean subset-sum reachability by bitset is `22`; value/count/witness knapsack variants are `29`; the split-and-join engine is `30` (`29` calls `30` for meet-in-the-middle, it does not duplicate it).
- Graphs `84-dynamictreedp.hpp` owns tree DP with updates; `41` is the chain engine only. Graphs `73-hamiltonian.hpp` owns the TSP API; `32` supplies the subset-transition engine. Graphs `14-tree_algorithms.hpp` supplies layouts for `15`.
- Owned elsewhere: two-heaps running/sliding median and top-k sums (Data Structures `25-heap_deque.hpp`); histogram and maximal rectangle (Data Structures `08-monotone_stack.hpp`); Mo and Hilbert-ordered range queries (Data Structures `23`, using `16`); bitset transitive closure (Graphs `40`); LCS and bitset LCS (Strings `19`); Josephus (Mathematics `19`); Sprague–Grundy and mex of game states (Mathematics `25`); exact static range mode (Data Structures `53`).
- Dinkelbach/fractional programming is owned here (`55`); Graphs `56`/`57` call it for mean cycle and density ratios. Tree (dependency) knapsack is owned here (`29`) because Graphs declines it.
