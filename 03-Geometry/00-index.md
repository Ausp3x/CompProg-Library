# 03 Geometry — inventory

Scope: planar and solid geometry with exact integral predicates and explicitly approximate long-double constructions: points, lines, polygons, circles, hulls, sweeps, triangulations, Voronoi/arrangement structures and their query APIs. Mathematics owns floor sums, polynomial root isolation and general LP; Data Structures owns range-tree, Fenwick and convex-hull-trick engines that geometry wrappers reuse; Graphs owns combinatorial planar embeddings and duals. Contracts, ownership rules and legacy obligations are in [80-notes.md](80-notes.md); the source ledger is in [81-sources.md](81-sources.md).

## Notes

- `98-Basic.hpp` includes every implemented Basic header (`01`–`09`); `99-All.hpp` currently includes the same nine headers and must gain each Advanced/Esoteric header as it is implemented. Planned headers are never included.
- Mathematics owns floor sums (`18-floorsum.hpp`, `55-floor_sum_polynomial.hpp`), real root isolation (`29-polynomial_roots.hpp`), ternary/golden search (`02-search_algorithms.hpp`), Simplex LP (`28-simplex.hpp`) and numerical integration (`17-numerical_methods.hpp`); rows 19, 25, 42 and 44 call them and do not duplicate them.
- Data Structures owns the range tree, Fenwick, Li Chao and convex-hull-trick engines (`43-rangetree.hpp`, `11-fenwick_tree_advanced.hpp`, `21-lichao.hpp`, `22-convexhulltrick.hpp`); `OLD/Team Notebook/src/geometry/lichaotree.cpp` is Data Structures legacy, not geometry.
- Graphs `29-planar_graph.hpp` owns combinatorial embeddings and duals; `33-linearrangement.hpp` exports to it instead of duplicating face logic.
- `08-Python/_11_geometry.py`, `_41_geometry_float.py` and `_44_exact_geometry.py` are documented Python reductions of rows 01–06, 12 and 14.
