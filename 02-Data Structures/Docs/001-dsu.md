## Contracts

### DSU

Vertices are `[0, n)` with `0 <= n <= INT_MAX`. The public `n`, `ncon`, `par` and `siz` must not be edited directly. Representatives are arbitrary and can change after a union. `findSet`, `size`, `isSameSet`, `leaders` and `groups` compress paths, so they are non-const. `uniteSets` returns whether two distinct components merged; `count` is the number of components. `groups` returns the components ordered by smallest vertex, each with members ascending, in O(n) time, workspace and output. `leaders` returns `findSet(u)` for every `u` in one vector, in O(n) time and output. `makeSet` appends the singleton vertex `n` and returns its id; it requires `n < INT_MAX`.

### Correctness and Cost

Union by size bounds the uncompressed depth by `log(n)`, which gives O(log(n)) worst-case find and unite; compression preserves the root equivalence relation and makes both inverse-Ackermann amortized. Initialization and storage are O(n). Sizes and the component count change only on successful unions. With no unions during grouping, each non-root edge is bypassed at most once, so grouping is O(n) including output. `makeSet` is a one-line composition of verified operations.

## Limits and Handoffs

The old DSU at `OLD/algorithms.cpp:1402–1477` mixed connectivity, weighted distances, parity and bipartiteness, and edge counts; its distance getter also narrowed `lng` to `int`. This row keeps the basic connectivity names and `n/ncon/par/siz`; no maintained consumers of the rest were found. The weighted three-argument unions, `dis`, `getDis`, `is_bip` and `isBipartite` are `WeightedDSU` and `ParityDSU` in `029-weighteddsu.hpp` ([029-weighteddsu.md](029-weighteddsu.md#legacy-mapping), P035); the component edge counts `esz`/`getEsiz` are `RollbackDSUAggregate::edgeCount` in `009-rollbackdsu.hpp` ([009-rollbackdsu.md](009-rollbackdsu.md), P034); Graphs owns dynamic-connectivity orchestration. Rollback, persistent and weighted DSU are separate rows, not gaps of this row. DSU grid adapters stay out, with the reason in [00-notes.md](00-notes.md#p006-re-audit-omissions) (user decision 2026-11-12).
