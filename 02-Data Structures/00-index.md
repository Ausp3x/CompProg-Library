# 02 Data Structures — inventory

Scope: this folder owns sequence, set, tree and persistent data-structure engines: DSU families, Fenwick/segment/sparse structures, balanced and implicit trees, heaps, tries over integers, offline range-query engines, dynamic trees and succinct structures. Graphs owns dynamic-connectivity orchestration, HLD and graph adapters; Geometry owns point-facing kd/range/rectangle-union APIs; Strings owns literal-prefix tries; Miscellaneous owns CDQ, parallel binary search, Hilbert ordering, hashing functions, slope trick and the generic undo log; Core owns accelerated bitsets and GF(2) matrices. Contracts, ownership rules and migration obligations are in [80-notes.md](80-notes.md); the source ledger is [81-sources.md](81-sources.md).

## Notes

- `00-monoids.hpp` is the shared legacy monoid header (MonAlg, MonBin, MonGcd, MonSar) owned by batch DS05 as support for `12-lazysegmenttree.hpp`; it has no row, is in All but not Basic, and its presets are listed in row 12.
- Rollback DSU owns the generic undo/connectivity substrate; weighted DSU owns potential/parity specializations without reciprocal includes. Graphs `26-dynamic_connectivity.hpp` owns edge-interval time decomposition over it; `63-offline_deletion.hpp` owns the generic non-graph add/remove engine.
- Area of union of rectangles is owned by Geometry `13-segment_union.hpp`; kd-trees and R/quadtrees by Geometry `28-spatial_index.hpp`; Hilbert ordering by Miscellaneous `16-hilbertorder.hpp`; slope trick by Miscellaneous `34-slope_trick.hpp`; hash functions by Miscellaneous `02-customhash.hpp`; generic undo log by Miscellaneous `42-rollback_framework.hpp`.
- GF(2) packed matrices (rank/solve/nullspace) are Core `12-bitmatrix.hpp`; `62-xorbasis.hpp` owns the incremental linear basis and its prefix/range variants. Python xor basis lives in `08-Python/_22_bitset.py`.
- Literal-prefix tries are Strings `04-trie.hpp`; CDQ and parallel binary search are Miscellaneous `21-cdq.hpp` and `20-parallelbinarysearch.hpp`; mex over game states is Mathematics `25-game_theory.hpp`.
- Legacy references in `97-Legacy/` stay until the owning row accounts for every feature; see [80-notes.md](80-notes.md) for the migration list.
