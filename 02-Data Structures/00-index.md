# 02 Data Structures — inventory

Scope: this folder owns sequence, set, tree and persistent data-structure engines: DSU families, Fenwick/segment/sparse structures, balanced and implicit trees, heaps, tries over integers, offline range-query engines, dynamic trees and succinct structures. Graphs owns dynamic-connectivity orchestration, HLD and graph adapters; Geometry owns point-facing kd/range/rectangle-union APIs; Strings owns literal-prefix tries; Miscellaneous owns CDQ, parallel binary search, Hilbert ordering, hashing functions, slope trick and the generic undo log; Core owns accelerated bitsets and GF(2) matrices. Contracts, ownership rules and migration obligations are in [00-notes.md](Docs/00-notes.md); the source ledger is [00-sources.md](Docs/00-sources.md).
