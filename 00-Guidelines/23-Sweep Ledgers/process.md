# Process Ideas

Ideas for the guidelines, skills, agents, hooks and `CLAUDE.md` found between process batches (`01-principles.md`, Scope Discipline, Rule freeze; user decision 2026-11-26). A session that finds one adds a line under Open instead of changing a rule. The next process batch's `/reflect` proposes each line to the user: an adopted idea becomes a rule with its entry in `10-decisions.md` and leaves this file, and a rejected one moves to Recorded Decisions so that nobody proposes it again.

Line format: `- YYYY-MM-DD | package or batch | idea | the rule text it replaces, or why none can go | evidence (a file, run or finding)`.
