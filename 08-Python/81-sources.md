All were feature/contract reads, no code adopted, no external correctness certification.

Reviewed-source traps that remain test requirements: PyRival `fst.py` inverse uses `/=` and converts integers to floats (exact inverse required here); ac-library-python `mincostflow.py` initializes potentials to zero, so negative-cost support cannot be inferred from edge acceptance; PyRival `SortedList` and `RangeMinimumQuery2` complexity claims need independent derivation; PyRival `dinic.py` uses recursive augmentation and a fixed capacity-scaling loop (iterative audit required); PyRival `mod.py` imports `__pypy__` unconditionally (guard required).
